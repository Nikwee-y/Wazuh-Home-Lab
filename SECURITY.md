# Security Policy

This repository is public documentation for a personal learning lab. Do not submit real credentials, private keys, VPN addresses, private hostnames, or raw endpoint data in issues or pull requests.

If sensitive data is accidentally committed:
1. Remove it from current files.
2. Revoke or rotate exposed credentials immediately.
3. Review the full Git history; a later deletion does not remove earlier commits.
4. Review releases, screenshots, logs, and forks for copies.
5. Share only sanitized reproduction details.
