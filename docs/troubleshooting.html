Troubleshooting guide

Work from service health to networking, configuration, and event ingestion. Change one variable at a time.

Docker / containers are stopped

systemctl status docker
systemctl status docker.socket
docker ps -a

If the service is disabled or stopped, decide whether you want the lab online before starting it. Review your deployment configuration and ensure sufficient resources.

Dashboard is unreachable

  1. Check dashboard container state and logs.
  2. Check manager and indexer health.
  3. Verify service bindings, routes, and firewall rules.
  4. Confirm private VPN connectivity if it is part of the access path.
  5. Do not expose the dashboard publicly as a quick fix.

Agent does not become active

  1. Confirm agent service state.
  2. Check the manager address in local agent configuration.
  3. Verify endpoint route and configured ports.
  4. Review endpoint and manager logs for registration, TLS, or authentication errors.
  5. Confirm enrollment steps match the installed Wazuh release.

Alerts do not appear

  1. Confirm the event source is enabled and produces events.
  2. Check agent connection and forwarding.
  3. Review manager logs, decoders, rules, and thresholds.
  4. Confirm indexer storage and dashboard access.
  5. Use a benign test event and verify the real event path end-to-end.

Before sharing logs

  • Redact IPs, VPN addresses, internal DNS names, and hostnames.
  • Remove usernames, personal paths, emails, and device identifiers.
  • Remove tokens, passwords, API keys, agent keys, and certificates.
  • Remove unrelated security events and personal data.
