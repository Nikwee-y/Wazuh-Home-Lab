RESPONSIBILITIES

What each component does

01

Wazuh Manager

Receives agent events, decodes them, evaluates rules, and generates alerts. Exact capabilities depend on configuration.

02

Wazuh Indexer

Stores and indexes event/alert data for search. Restrict it to required internal services.

03

Wazuh Dashboard

Provides the interface for reviewing alerts, exploring events, and using supported Wazuh features.

04

Wazuh Agent

Runs on a monitored endpoint and sends configured telemetry to the manager. Enroll authorized lab systems only.

05

Docker

Runs Wazuh services as containers on the Arch Linux host. Service availability depends on Docker running.

06

Private network

A private VPN overlay was used for remote access. VPN membership does not replace firewalls or authentication.
