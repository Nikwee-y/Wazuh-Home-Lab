07 / FUTURE ITERATIONS

Roadmap & planned integrations

The goal is to evolve from a Wazuh-centered learning lab into a more complete SOC workflow. Every item below is a proposal until installed, integrated, tested, and documented.

Planned—not currently implemented

Suggested implementation phases

  1. Phase 1 — Stable Wazuh baseline

    Bring Docker services online, verify the three core services, enroll authorized endpoints, and test a benign event.

  2. Phase 2 — Detection quality

    Document useful alerts, enable selected Windows/Linux sources, tune noise, and create repeatable validation.

  3. Phase 3 — Case management and enrichment

    Evaluate TheHive and threat intelligence with synthetic events and documented integration boundaries.

  4. Phase 4 — Automation and AI

    Add approval-gated playbooks and optional AI summaries with data minimization and human review.

  5. Phase 5 — Network visibility

    Assess resource requirements before introducing Zeek/Suricata or an additional Elastic/Kibana stack.

Definition of done

  • Architecture and data-flow diagrams updated.
  • Version compatibility and resource needs documented.
  • Secrets and service exposure reviewed.
  • Positive/negative tests recorded with sanitized evidence.
  • Failure, rollback, and data-retention behavior documented.
  • Status changed from Planned only after validation.
