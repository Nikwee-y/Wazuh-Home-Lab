Operational state

Earlier notes indicated Docker and docker.socket were disabled and Wazuh containers stopped. Current state has not been rechecked. Do not assume services are online.

SAFE WORKFLOW

Deployment / recovery sequence

  1. Check host services

    Confirm resources, time synchronization, and Docker service state.

    systemctl status docker
systemctl status docker.socket
docker ps -a
  2. Review private deployment directory

    Use the actual local directory containing your Compose file. Do not publish private Compose or environment files without redaction.

    docker compose config --quiet
docker compose ps
  3. Start services only when ready

    Use your known-good Compose configuration and official version-matched guide. Do not recreate or replace existing configuration based only on this public documentation.

    docker compose up -d
docker compose ps
docker compose logs --tail=100
  4. Validate end-to-end

    Check service health, trusted dashboard access, agent connection, and alert ingestion.

  5. Record results safely

    Document outcomes and sanitized errors. Keep addresses, credentials, raw logs, and private configuration local.

Version and upgrade discipline

  • Verify running image tags rather than relying on old notes.
  • Read release notes and version-specific upgrade guidance.
  • Back up configuration and persistent data securely.
  • Validate agents, alert ingestion, dashboard access, and storage after changes.
